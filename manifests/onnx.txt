# The ONNX files this build names by BLAKE3, one `<repo> <path>` per line.
#
# Each is the file Hologram AI's milestone 2 loads: the q4 and q4f16 graphs of
# five exports, the external data a graph keeps its weights in, and the four
# JSON files beside them. `tools/index.mjs` streams every one and puts the
# BLAKE3 of its whole bytes in the release record (HK-45), and
# `tools/uor-index.mjs` streams the graphs and their data again and publishes
# every initializer's byte range and BLAKE3 (HK-46). The second pass also
# hashes each whole file and refuses it unless it is the BLAKE3 the record
# names, so the two passes check each other.
#
# A list rather than a rule, so what a build will spend is readable before it
# spends it: 7.6 GB in all at the revisions below, measured 2026-11-18. A path
# the release does not hold fails the build; the list and the index agree or
# the build says so. The records are of each model's current revision, which

# The three ONNX models the Q engine loads, so that it can pull them from this
# hub rather than from huggingface.co. What a manifest gives for these is
# narrower than for the models above, and the difference is not a defect: the
# witness reads tensors from safetensors headers, and these repositories carry
# none - 10, 12 and 12 .onnx files against 0 safetensors. Every file over 10 MB

# witnessed: false, and no tensor in them has an address this repository
# checked. An ONNX layout reader is what would change that, and it is not
# built.
